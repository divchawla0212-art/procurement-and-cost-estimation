Scope of supply

A hosted platform that ingests a complete tender package — every vendor folder, in whatever mix of formats it arrives in — and returns a traceable comparative statement. Each document is classified, revision lineage is resolved so superseded issues never contaminate the comparison, and technical parameters, commercial terms and deviations are extracted with every figure traceable to the page it came from.

Compliance is decided in code, not by the language model. The model reads and reports what a document says; the pass/fail arithmetic against your specification is deterministic and auditable. An unfound parameter is reported as unfound — never silently defaulted to zero or to a pass.

How capacity is measured

  1. You are billed on the size of the files you submit, in megabytes, rounded up once per tender at the run level — never per document.
  2. You never pay twice for the same document. Re-submitting a file that has not changed is free; the platform recognises it and reuses the existing extraction.
  3. Failed extractions are credited back in full. You pay for facts, not for attempts.
  4. Each tender is billed within a 20–120 MB band, so a drawing-heavy package cannot run away with your capacity, and a small one still carries its share.
  5. You see the cost before it is incurred. Uploading a package returns the exact megabytes and the resulting balance; nothing is processed until you proceed.
  6. Capacity is valid 12 months from purchase and rolls over once on renewal.
